О сайте

Этот сайт посвящён авиационной технике России. Основной функционал включает:

  • Просмотр каталога техник с изображениями
  • Открытие детальной страницы каждой техники с её описанием и изображением
  • Форма обратной связи для отправки сообщений администратору
  • Административная панель для просмотра и управления сообщениями пользователей
  • Авторизация и права доступа для администрирования контента.
